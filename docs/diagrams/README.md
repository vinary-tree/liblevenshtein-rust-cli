# Diagram sources

The diagrams use PlantUML because it provides well-defined component and
activity notations and reproducible SVG output. Every source has a committed
sibling SVG generated by `render.sh`.

| Source | View | Why this diagram type |
|---|---|---|
| `application-boundary.puml` | component diagram | Shows ownership and dependency direction across crates and adapters. |
| `grep-ingestion.puml` | activity diagram | Shows every optional ingestion branch, resource guard, matching stage, and output. |

Color is semantic: purple denotes people/process entry points, blue denotes CLI
coordination, orange denotes untrusted-input adapters, green denotes reusable
libraries, yellow denotes resource guards, and red denotes rejected input.

```bash
docs/diagrams/render.sh
docs/diagrams/render.sh --check
```

Edit `.puml` sources, never generated `.svg` files.
